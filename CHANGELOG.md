# Changelog

## 1.0.0

First public release, focused on usernames and nicknames.

- One search workflow with Quick and Deep service scopes.
- Account sections by service, distinct similar-name and published-link labels,
  evidence references and source check details.
- Saved results, stop and continue actions, and readable/text/JSON exports.
- English interface with a persistent Russian option.
- Supported extraction, original Maigret settings and saved-data tools.
- Local storage and a compiled Windows x64 core.

Service availability changes independently of application releases. Incomplete
checks and source restrictions remain visible in result details. Bugs may occur
in this first release; include the application version when reporting them.
