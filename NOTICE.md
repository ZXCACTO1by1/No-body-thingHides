# Licensing and component boundaries

No[body]thingHides is free to use and contains a proprietary compiled core. The
published repository contains its client, contracts and documentation. The
[original-material license](LICENSE) grants free use and limited source rights;
this is not an open-source license for the entire application.

Maigret and SOCID retain their MIT licenses. WhatsMyName source data and the
combined derived service presentation dataset retain CC BY-SA 4.0 terms. Original
code that uses those datasets is a separate component. CPython, native libraries,
interface libraries and other dependencies retain their respective licenses.

The Windows distribution includes THIRD_PARTY_NOTICES.md, exact component license
texts and a software license inventory. Required corresponding source and
replacement instructions accompany the matching binary. The inventory, rather
than a general statement in this document, identifies the shipped versions.

Third-party copyright notices are retained. The original-material license does
not override upstream rights. Compatible replaceable libraries remain accessible
in the upstream runtime directory.
