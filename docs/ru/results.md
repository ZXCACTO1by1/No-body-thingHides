# Как читать результаты

Каждый сервис имеет отдельный раздел. Разные ники Telegram остаются разными
аккаунтами; одинаковые ники на разных сервисах не объединяются. Совпадение имени
не доказывает общего владельца.

«Точный ник» означает проверенное совпадение написания, «Похожий ник» — проверенный
вариант, «Опубликованная ссылка» — заявленную источником и отдельно проверенную
ссылку. Один установленный аккаунт может иметь несколько меток и подтверждений.

Кандидаты — данные для дальнейшей проверки, а не подтверждённые карточки аккаунтов.
В представлении всех проверок доступны ограничения источников, ошибки и
непроверенная работа. Недоступный источник не равнозначен отсутствующему аккаунту.

Отчёт для чтения и текстовый отчёт разделяют аккаунты по сервисам. Полный JSON
сохраняет машинные поля и ссылки на подтверждения. Перед публикацией проверьте
содержимое: ники, страницы и ответы источников могут содержать персональные данные.
Подробнее — [английский справочник состояний](../results.md).
