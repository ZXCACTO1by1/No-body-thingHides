# Быстрый старт

Распакуйте весь архив Windows x64 и запустите `Start.cmd` или
`NoBodyThingHides.exe`. Программа откроет локальный интерфейс в браузере.
Выберите русский язык, введите ник без `@` и адреса профиля, затем начните поиск.

Быстрый режим выбирает популярные сервисы, глубокий — весь подходящий каталог.
Оба используют одинаковые применимые этапы. Глубокому поиску может потребоваться
значительное время. Лимиты, нагрузка и глубина находятся в раскрываемых настройках.

Результаты сгруппированы по сервисам. Откройте раздел для просмотра аккаунтов и
подтверждений. Остановка сохраняет прогресс; «Продолжить» возобновляет план.
Данные по умолчанию лежат в `%LOCALAPPDATA%\NoBodyThingHides`.

Это первый публичный выпуск: возможны ошибки и изменения доступности сервисов.
Читайте [значения результатов](results.md) и [о хранении данных](privacy.md).
Для переносной папки данных доступен параметр [CLI](../cli.md) `--home`.

## Инструменты и исследования

Инструменты сгруппированы по назначению; есть поиск и фильтр группы.
Панель «База исследований» показывает готовность локальной базы. Для подготовки
откройте «Подготовить базу данных» и нажмите «Выполнить». Отсутствие входных полей
у этой операции правильно: ей не нужны значения.

Отчёт поиска по нику в «Результаты» и именованное исследование в базе — разные
объекты. Для инструментов базы подготовьте её, создайте исследование с понятным
названием, добавьте исходные объекты с их типами и запустите нужные проверки.
Новые исследования сразу появляются в формах, без перезагрузки страницы.
Выбирайте по названию; под списком раскройте «Идентификатор выбранного объекта»,
чтобы увидеть и скопировать полный внутренний номер. Объекты и запуски фильтруются
по выбранному исследованию. Отсутствие данных и ошибка чтения базы объясняются отдельно.

После запуска откроется «Текущая работа». У завершённого инструмента нажмите
«Посмотреть вывод инструмента», у поиска — «Открыть результат». Из вывода можно
открыть упомянутое сохранённое исследование. Вывод может содержать ваши данные:
проверьте его перед отправкой другим людям. «Показать предыдущие операции»
раскрывает ограниченный список последних заданий. Остановка и продолжение
доступны после перезагрузки страницы.

Обязательные поля отмечены `*`; ошибочное поле выделяется и получает фокус.
Во время работы можно читать результаты и редактировать настройки. Ключи задаются
отдельной формой системного хранилища; парольные поля очищаются при закрытии.
Для файла нажмите «Выбрать файл» или выберите сохранённый отчёт. Общий размер
загрузки — до 8 МБ. Ограничения внешних источников сохраняются.
