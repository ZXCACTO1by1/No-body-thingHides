# Frequently asked questions

## Is it free?

Yes. The application has no license activation or required subscription. Optional
external services may have their own account requirements or charges. They are
not required for the main username workflow. See the [license](../LICENSE).

## Does Deep use a different search engine?

Both modes use the same applicable stages. Quick chooses popular services; Deep
chooses the full eligible catalogue. Source availability, input compatibility and
your resource settings determine which checks can complete.

## Does a matching handle prove a common owner?

No. Review [result interpretation](results.md). Names, links and source identifiers
must not be silently treated as proof of a person's identity.

## Why is a known service blocked or unknown?

Services change their pages, access rules and request limits. A failed check can
leave a gap even when an account exists. Check details and evidence distinguish
these outcomes from supported negative results.

## Can I build the entire application from this repository?

The repository builds the public client. The original core is supplied as a
compiled release asset. Upstream components keep their own source and replacement
rights. See [client build](build-client.md) and [architecture](architecture.md).

## What should I attach to a bug report?

Version, Windows version, steps and a small synthetic example. Review and redact
any diagnostic attachment. Never attach an entire private case or credentials.
