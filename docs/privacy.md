# Privacy and storage

The application keeps its database, saved jobs, evidence and reports in the chosen
local data directory. It does not require a cloud account or send automatic
telemetry. The interface uses local/system assets rather than remote fonts,
analytics or provider favicons.

Searching makes network requests to the relevant public services. A service can
observe the requested username, your network address and its own request metadata.
Follow its access rules. A denied request remains a source gap; it is not evidence
that the account is absent.

Optional analysis is a separate action. Review the selected case, endpoint and
model before confirming transmission. It sends the selected public profile data
and references to your chosen service. That service's terms and retention policy
apply. An optional session key is used for that launch; service credentials are
managed separately in the system secret store.

Readable reports can contain personal information. Complete JSON and evidence may
contain more data than the interface shows. Text output redaction is a convenience,
not a guarantee that it is safe to publish. Review contents and filenames yourself.

Back up your data directory if you want to retain cases. Delete only folders you
intend to remove; uninstalling application files does not require deleting history.
