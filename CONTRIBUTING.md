# Contributing

Useful contributions include reproducible client bugs, accessibility improvements,
English/Russian wording corrections, contract tests and documentation fixes.
Read the [client build instructions](docs/build-client.md) before changing code.

Explain the user problem and include a small synthetic reproduction. Keep changes
focused. Check both languages, keyboard use and narrow layouts for interface work.
Avoid new dependencies unless they solve a concrete problem.

The engine source is private. Public pull requests cannot rebuild it; requests
that change its behavior should describe the expected result and supporting
public source information. The maintainer decides the engine roadmap.

Read [contribution terms](CONTRIBUTION_TERMS.md) before submitting original
material. Retain upstream attribution. Never attach credentials, raw evidence,
personal case folders or private datasets to an issue or pull request.
